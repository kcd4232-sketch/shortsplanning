# 뷰티 릴스·쇼츠 기획

## 시작점

현재 작업 폴더에서 `beauty_reels_automation_prompt_v2_3.md`를 찾아 읽는다. 보통 `outputs/`에 있고 Codex 작업 묶음에서는 `instructions/`에 있다. 이전 V2.2의 10편·40/30/30 설정보다 최신 사용자 결정과 V2.3을 우선한다. 기존 원고 JSON, HTML, 이미지, 검증 스크립트가 있으면 재사용한다.

## 공개 레퍼런스 조사

- 기본 계정은 `@amazingvictoria_gn`, `@spahara_academy` 두 곳이다. 사용자가 요청하거나 승인하지 않은 계정은 기본 분석 집단에 추가하지 않는다.
- Chrome을 사용하지 않는다. 사용자가 선택한 Edge가 연결되면 우선 사용하고, 접근이 막히면 허용된 공개 경로로 확인 가능한 범위의 조사를 계속한다. 제한을 우회하지 않는다.
- URL, 게시 계정, 게시일, 수치별 확인 시각·경로를 기록한다. 3배 조회수 **성과 사례**와 캡션 주제만 확인된 **주제 참고 사례**를 구분한다. 후자에서 실제 컷·압력·효과·성과 원인을 추정하지 않는다.

## 기획과 이미지

- 현재 기본 납품은 교육형 2편 + 관리 시연형 3편이다. 사용자가 수량이나 유형을 바꾸면 최신 요청을 따른다. 교육형은 배우고 싶게, 시연형은 받아보고 싶게 만들고 각기 실제 교육 안내 또는 서비스 상담으로 이어지는 CTA 하나를 둔다.
- 편마다 새 훅, 컷별 촬영 순서·읽을 대사·자막·편집, 게시 문구를 완성한다. 확인된 원본 정보와 새로 창작한 장면을 구분한다. 공통 촬영 전 체크리스트는 반복하지 않는다.
- 편마다 주제·후킹·타깃 근육점·핵심 메시지·CTA를 짧게 보여주는 요약을 둔다. 타깃 근육점은 접촉 부위 아래의 대략적인 위치로 표현한다.
- 이미지 시안에는 촬영·게시에 동의한 성인 사람을 사용한다. 마네킹·실리콘 인체 모형은 사용하지 않는다. 마사지 부위의 피부와 손 접촉 위치가 보이고, 받는 사람은 대체로 누운 자세로 구성한다. 나머지 노출은 필요한 만큼 가린다.
- 편당 3장: 접촉 위치, 약 80% 투명해 보이는 근육·근막 **개념도**, 교육/관리 시연. 둘째 장면의 해부학 이름과 대략적 위치를 권위 있는 자료로 확인한다. 생성 이미지는 실제 고객이나 결과가 아니며 특정 조직의 자극 깊이·치료 효과의 증거가 아니다. 이미지 생성·편집은 사용 가능한 imagegen 도구와 그 스킬을 따른다.

## HTML과 확인

- 다른 기기에서도 한 파일로 볼 수 있도록 사진을 HTML 안에 넣고 외부 이미지·글꼴·CSS·JS 파일에 의존하지 않는다. 레퍼런스 링크만 온라인 연결이 필요할 수 있다.
- 현재 프로젝트에서는 `work/build_beauty_5_scenarios.mjs`와 `work/verify_beauty_anatomy_html.mjs`를 사용한다. 작업 묶음에서는 `scripts/` 아래 같은 파일을 찾는다. 이미지가 바뀌면 원고의 자세·의상·접촉 부위 설명도 맞춘다.
- 납품 전 5편 구성, 고유 이미지 15장, 내장 이미지, 해부학 출처, 확인 날짜, 외부 파일 의존, 모바일 가독성을 확인한다. 공유용 HTML과 편집용 작업 묶음은 목적을 구분한다.
- 정기 자동화의 기획 기준을 바꾸는 경우 현재 자동화 설정을 확인하고 새 지침 버전과 일치시키되 기존 일정과 알림 설정은 유지한다.
