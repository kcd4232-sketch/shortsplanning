# 뷰티 릴스 기획 방향 개정 — 교육형·시연형 중심

**적용일:** 2026-10-26  
**대상:** 이번 10편 촬영 기획과 이후 기획 검토  
**관계:** 기존 V2.2의 공개 조사·사실 검증·안전 기준을 유지하며, 이번 기획의 콘텐츠 유형 구성만 교육형 5편과 시연형 5편으로 조정한다.

## 제작 대상과 목적

- 주 시청자는 피부·얼굴·목·어깨·발·두피 관리에 관심 있는 일반 고객으로 둔다.
- 전문가의 지식은 쉬운 설명으로, 실제 서비스 역량은 손·도구·준비 과정의 시연으로 보여준다.
- 별도 고객 관심형을 두지 않는다. 상담·예약 유도는 교육이나 시연에 자연스러운 한 가지 CTA로 넣는다.
- 목표는 조회수만이 아니라 저장·완주·프로필 방문·실제 상담을 함께 보는 것이다. 경쟁 계정의 비공개 예약이나 성과를 추정하지 않는다.

## 10편 구성

- **교육형 5편:** 각 영상은 시청자가 바로 이해하거나 다음 상담에 사용할 수 있는 지식 한 가지를 다룬다.
- **시연형 5편:** 각 영상은 손이나 도구로 한 가지 절차를 처음부터 끝까지 보여준다.
- 매 영상은 20~35초, 4~5컷을 기본으로 한다. 첫 3초에 주제와 시각적 행동이 함께 나오게 한다.
- 10편이 같은 3단계 체크리스트가 되지 않게 비교, 숫자·압 스케일, 도구 시범, 질문·답, 한 번에 이어지는 과정 등 형식을 순환한다.
- 컷별 대사, 자막, 카메라 위치, 손동작, 전환을 구체적으로 적는다. “관리 장면을 보여준다” 같은 추상 지시만으로 끝내지 않는다.

## 근거와 제안 구분

1. 경쟁 계정에서 확인한 팔로워·조회수·게시 날짜·캡션 내용과 확인 시각을 출처별로 기록한다.
2. 원본 영상의 재생이 막히면 첫 3초, 실제 동작, 편집, 음원, 영상 길이를 본 것처럼 적지 않는다.
3. 참고 링크는 아이디어 방향을 살피는 자료다. 원본 대사·영상 장면·음원을 복제하지 않는다.
4. 확인된 공개 구성과 새로 제안한 대본을 별도 상자로 구분한다. 높은 조회수와 특정 구성 사이의 인과는 실험 전까지 가설로 쓴다.
5. 이번 기획처럼 최신 레퍼런스 데이터가 갱신되지 않았으면 기존 스냅샷 날짜를 표시하고, 새로운 성과 분석이나 순위로 포장하지 않는다.

## 반복·품질 점검

각 편마다 다음 질문에 모두 답할 수 있어야 한다.

- 누구의 어떤 구체적인 상황을 다루는가?
- 이 영상을 보고 시청자가 무엇을 이해하거나 확인하게 되는가?
- 교육형은 설명의 시각 자료가 있는가? 시연형은 실제 행동의 시작과 끝이 보이는가?
- 같은 10편 안에서 훅, 화면, 전개 방식이 다른 영상과 구별되는가?
- 첫 3초에 주제가 보이고, 나머지 컷이 그 약속을 끝까지 설명하는가?
- 샵에서 스마트폰과 적은 소품으로 재현할 수 있는가?
- CTA가 하나뿐인가?
- 의료 진단·효과 보장·부종/림프/리프팅 등 확인되지 않은 효능을 암시하지 않는가?
- 고객 얼굴·개인 정보·전후 사진을 별도 동의 없이 사용하지 않는가?

같은 문제 상황·훅·3단계 구조가 3편 이상 반복되면 중복을 줄이고, 각 편의 화면 행동부터 다르게 다시 짠다.

## 게시 후 학습

- 게시 후 24시간·72시간·7일에 플랫폼 자체 인사이트를 기록한다.
- 교육형은 시청 지속·저장·공유, 시연형은 완주·반복 시청·저장 신호를 우선 비교한다.
- 프로필 방문·DM·상담·예약은 실제로 연결을 확인할 수 있을 때만 기록한다.
- 작은 표본에서 성공 원인을 단정하지 않는다. 다음 회차는 한 번에 훅 또는 촬영 방식 한 요소씩 바꿔 비교한다.

## 현재 작업 환경 권고

- **Chat:** 아이디어 방향을 짧게 논의하고 비교안을 고를 때 사용한다.
- **ChatGPT Work:** 자료 여러 개를 읽고 기획문·정리된 문서를 완성해 검토할 때 적합하다. 데스크톱에서 로컬 파일·브라우저 사용은 해당 도구와 권한이 제공될 때만 가능하다.
- **Codex:** 현재 HTML, 생성 스크립트, README와 ZIP처럼 실제 폴더의 파일을 함께 수정하고 변경 내용을 검토할 때 사용한다.
- 이번 프로젝트는 Codex를 산출물 제작의 기준 작업 공간으로 두고, Chat에서 방향을 합의하거나 Work에서 리서치·초안을 다듬은 뒤 Codex에서 최종 파일에 반영하는 흐름을 권한다. Work와 Codex는 작업 기록과 로컬 설정 접근이 자동으로 합쳐지지 않으므로, 최종 변경은 파일에 기록한다.

**레퍼런스 사용 주의:** @spahara_academy처럼 뷰티 종사자 교육을 주로 하는 계정은 시청자가 일반 고객과 다를 수 있습니다. 해부학 용어나 수강 모집 CTA를 그대로 옮기지 말고, 고객이 관리 과정을 이해하고 자기 선호를 표현하도록 쉽게 번역합니다.

## 시안 이미지와 초보 촬영 안내

- 우선 촬영 3편의 대표 4컷을 생성형 이미지 시안으로 보여준다. 인물·관리 장면은 실제 고객이나 실제 촬영 결과가 아니라 구도 참고용이다.
- 각 컷을 따로 녹화하고, 녹화 전후 1초 여유를 두며, 실수한 컷만 다시 찍는 과정을 HTML에 추가한다.
- 화면 자막은 표의 문구를 그대로 사용하고, 두 줄 이내로 손동작과 얼굴을 가리지 않게 배치한다.
- 이미지가 HTML에 포함되어 파일 하나만 열어도 보인다. 재생성할 때는 planning/assets/의 이미지 원본이 필요하다.
