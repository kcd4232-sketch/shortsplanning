# 뷰티 릴스·쇼츠 경쟁 분석 및 촬영 기획 지침 V2.3

**개정일:** 2026-10-28  
**현재 납품 기준:** 교육형 2편 + 관리 시연형 3편, 총 5편. 사용자가 수량·유형을 새로 지정하면 그 요청을 따른다.

## 1. 목표와 조사 범위

- 조회수와 실제 교육 문의·관리 상담·예약을 별도 목표로 다룬다. 조회수가 높다는 사실만으로 고객 유입을 주장하지 않는다.
- 기본 분석 계정은 `@amazingvictoria_gn`, `@spahara_academy` 두 곳이다. 추가 계정은 사용자가 요청하거나 승인한 범위에서만 본 분석에 포함한다. 공동 게시 계정도 실제 게시 주체와 구분한다.
- Chrome 브라우저를 사용하지 않는다. 사용자가 지정한 Edge를 우선하고, 연결되지 않거나 공개 화면이 제한되면 Whale, 허용된 공개 검색 결과, 공식 페이지, 정당하게 연결된 도구 등 가능한 경로로 계속 조사한다. 로그인·접근 제한을 우회하지 않는다.
- 각 사실과 수치에 URL, 확인 경로, 확인 시각(Asia/Seoul), 게시 계정을 기록한다. 확인되지 않은 항목은 `확인 불가`로 적고 0이나 추정치로 채우지 않는다.

## 2. 레퍼런스 수집과 구분

1. 최근 30일을 우선 탐색한다. 조회수/확인된 팔로워 수가 3배 이상인 영상이 10개 미만이면 60일, 최대 90일까지 범위를 넓힌다. 조건을 완화해 3배 영상인 것처럼 표시하지 않는다.
2. **성과 검증 사례:** 게시 계정, 게시일, 현재 팔로워 수, 영상 조회수가 확인된 릴스. 조회수 배율을 계산할 때 팔로워 수와 조회수의 확인 시점 차이를 표기한다. 광고·협찬이 확인되면 별도로 표시한다.
3. **주제 참고 사례:** 게시 계정·날짜·공개 캡션 주제는 확인됐지만 조회수, 화면 내용 또는 손동작은 확인되지 않은 릴스. 기획 소재에는 쓸 수 있지만 바이럴 순위나 원본 영상 구조 분석에는 넣지 않는다.
4. 접근이 제한된 영상의 실제 첫 3초, 컷 순서, 대사, 손 압력, 고객 반응, 저장·공유 수, 광고 여부를 추정하지 않는다. 원본에서 확인된 정보와 새로 제안한 장면을 항상 분리한다.
5. 기존 URL은 중복 추가하지 않고 확인 시각과 수치만 갱신한다. 최신 화면을 다시 보지 못했다면 과거 조사 날짜를 현재 확인으로 바꾸지 않는다.

성과가 좋은 이유는 확인 가능한 구조와 성과 사이의 **가설**로만 제시한다. 시청 유지율이나 전환 자료 없이 인과관계를 단정하지 않는다.

## 3. 이번 5편의 콘텐츠 방향

- **교육형 2편:** 예비 관리사·실무자가 손 위치와 기본 자세를 배우고 싶게 한다. 공식 교육 커리큘럼으로 이어지는 CTA 한 가지만 둔다.
- **관리 시연형 3편:** 잠재 고객이 손길·진행 순서·편한 압 확인을 보고 관리를 받아보고 싶게 한다. 실제 운영 중인 상담·예약 경로로 이어지는 CTA 한 가지만 둔다.
- 각 편은 한 가지 전문 포인트와 한 가지 시청자 욕구에 집중한다. 타인의 대사·편집·음원·독특한 장면을 복제하지 않는다.
- 실제 제공하지 않는 교육·서비스·효과를 약속하지 않는다. 통증 개선, 체형 변화, 얼굴선 변화 같은 결과를 입증 없이 주장하지 않는다.

## 4. 5편 각각의 납품 항목

각 편의 앞부분에 **한눈에 보는 요약**을 두고 `주제 · 후킹 · 타깃 근육점 · 핵심 메시지 · CTA`를 각각 짧게 표시한다. 타깃 근육점은 사진 속 손이 닿는 표면 아래의 대략적인 위치로 설명하고 실제 자극 깊이를 단정하지 않는다.

1. 제목, 교육/시연 구분, 대상 시청자, 목적, 예상 길이
2. 레퍼런스 URL과 **확인된 사실**, 새 기획에서 **창작한 부분**
3. 새 썸네일 문구와 0~3초 훅
4. 시간 순서대로 읽을 수 있는 컷별 표: 카메라 위치·행동, 실제 읽을 대사, 화면 자막, 편집 지시
5. Instagram 캡션, YouTube Shorts 제목·설명, 단일 CTA
6. 관리 부위·동작의 표현 유의점과 해부학 참고 출처
7. 이미지 3장: 손이 닿는 피부가 보이는 장면 / 해당 근육·근막의 대략적 위치 개념도 / 실제 사람을 대상으로 한 교육 또는 관리 시연

공통 촬영 전 체크리스트나 별도 우선 촬영 지시 섹션을 반복하지 않는다. 필요한 실제 행동은 컷별 표에 적는다. 사진 3장은 위치와 분위기를 이해하기 위한 시안이고, 시간표의 컷 수와 같을 필요는 없다.

## 5. 사람과 해부학 이미지

- 관리·교육 장면은 촬영·게시에 동의한 성인 사람을 기준으로 만든다. 마네킹, 인체 모형, 실리콘 연습 도구를 사람 대신 쓰지 않는다.
- 이번 5편의 사진은 대부분 관리대에 누워 관리를 받는 모습으로 구성한다. 손이 닿는 부위의 피부는 보이게 하고 나머지는 의복·타월로 필요한 만큼 가린다. 실제 촬영의 노출 범위는 출연자의 동의와 편안함에 맞춘다.
- 각 편의 둘째 이미지는 손이 닿는 표면 아래의 근육·근막을 **약 80% 투명하게 보이도록 한 생성형 개념도**다. 투명도는 시각적 목표이며 픽셀 단위의 측정값이라고 주장하지 않는다. 근육 이름과 대략적 위치를 신뢰할 수 있는 해부학 자료로 확인한다.
- 피부 접촉 사진이나 오버레이만으로 특정 조직을 실제로 자극한 깊이, 근막 변화, 치료 효과를 주장하지 않는다. 생성 이미지는 실제 고객·관리 결과로 소개하지 않는다.
- 이미지 생성이 제한되면 가능한 시안을 만들고 누락·차이를 표시한다. 허용되지 않은 접근이나 브라우저 정책 우회로 이미지를 얻지 않는다.

## 6. 공유용 HTML 형식

- 모바일에서 5편을 빠르게 찾을 수 있는 목차와 각 편의 3장 이미지, 컷별 대본을 넣는다. 확인된 레퍼런스 정보와 창작 기획은 시각적으로 구분한다.
- HTML은 **한 파일만 다른 기기로 보내도** 본문과 사진을 볼 수 있게 한다. 이미지 15장을 파일 내부에 넣고 외부 이미지·글꼴·스타일·스크립트 파일에 의존하지 않는다. 레퍼런스 URL은 인터넷이 있을 때만 열리는 외부 링크임을 구분한다.
- 사진마다 무엇을 볼지 짧은 설명을 넣고, 둘째 사진은 `해부학 개념도`로 표시한다. 생성 이미지 및 관리 효과 미확인 표기를 눈에 띄게 둔다.
- 인쇄와 작은 화면에서 표·사진이 읽히는지 확인한다. 같은 사진을 목차와 본문에 두 번 보여줘도 **서로 다른 원본 이미지는 15장**이어야 한다.
- 저장 전 5편 수, 교육 2편/시연 3편 구분, 15장 고유 이미지, 이미지 내장 여부, 외부 파일 의존, 잘못된 출처·날짜·표현을 확인한다. 이 프로젝트의 검증 스크립트는 `work/verify_beauty_anatomy_html.mjs`다.
- 사용자가 ZIP을 원하면 HTML만 담은 공유용 ZIP과 편집 가능한 Codex 작업 묶음을 구분해서 제공한다.

- 이전 5편과 다른 새 기획은 실제 확인된 주제 변화 또는 명시된 사용자 요청에 근거한다. URL과 아이디어가 실질적으로 중복되지 않게 한다.
- 조치가 필요한 변화가 없으면 정기 실행은 조용히 끝낸다.
